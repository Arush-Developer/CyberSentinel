## Potentially misleading features

- `record_id`: identifier whose numbering clusters by class. Never a model input.
- `Destination Port`: near-deterministic for some classes in this capture. Dropped from both models after the port study showed no macro-F1 gain; kept as network metadata.
- `Init_Win_bytes_forward` and similar TCP fingerprints: almost constant within each attack class, so they describe this capture's attack tools and may not generalise.
- Rate features such as `Flow Bytes/s`: originally prone to infinities in CICIDS2017. This pack has none, but the pipeline still handles them.
- Measured leakage audit: `data/reports/leakage_audit.json`.
